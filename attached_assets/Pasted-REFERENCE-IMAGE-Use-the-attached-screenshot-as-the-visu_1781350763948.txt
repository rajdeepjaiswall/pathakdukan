ORDER CLASSIFICATION LOGIC

Upcoming Orders:
- Any order that is Pending, Processing, Packed, Shipped, Out for Delivery, or any status other than Delivered.
- These orders remain under the "Upcoming Orders" heading.

Past Orders:
- Any order marked as Delivered from the Admin → Orders panel.
- Once an order status becomes Delivered, automatically move it from Upcoming Orders to Past Orders.
- Preserve all existing order data, date, order number, amount, address, status, etc.
- Only the section heading changes from Upcoming Orders to Past Orders.
