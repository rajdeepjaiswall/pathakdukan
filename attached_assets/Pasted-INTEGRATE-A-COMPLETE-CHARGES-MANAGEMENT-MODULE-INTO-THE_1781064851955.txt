IMPORTANT:
- Do NOT modify existing cart logic.

==================================================
ADMIN DASHBOARD
==================================================

Create a new dashboard card:

Title: Charges
Icon: Receipt / Calculator / Charges

When opened, show two independent sections:

1. Delivery Charges
2. Handling Charges

Both sections must work independently.

==================================================
DELIVERY CHARGES SECTION
==================================================

MASTER SWITCH

Delivery Charges [ON/OFF]

If OFF:
- Delivery charges completely disabled.
- No delivery charges calculated.
- No delivery charge row shown in cart.
- No delivery charge row shown in checkout.
- No delivery charge row shown in order summary.

If ON:
- Delivery charge logic becomes active.

--------------------------------------------------

FREE DELIVERY THRESHOLD

Toggle:
Enable Free Delivery Threshold [ON/OFF]

Input:
Free Delivery Above Amount (₹)

Example:
₹350

Logic:

If cart subtotal >= threshold amount

Delivery Charge = ₹0

Display:

Delivery: FREE

--------------------------------------------------

CHARGE TYPE

Only ONE option can be selected.

Radio Style:

( ) Percentage Charge
( ) Fixed Charge

Mutually Exclusive.

Selecting one automatically deselects the other.

--------------------------------------------------

PERCENTAGE CHARGE

Visible only when Percentage Charge is selected.

Input:

Percentage %

Example:

5%

Calculation:

deliveryCharge =
(cartSubtotal × percentage) / 100

Example:

Cart ₹200
Percentage 5%

Delivery = ₹10

--------------------------------------------------

FIXED CHARGE

Visible only when Fixed Charge is selected.

Input:

Fixed Delivery Charge

Example:

₹50

Calculation:

deliveryCharge = fixedAmount

==================================================
CHECKOUT CALCULATION FLOW
==================================================

STEP 1

Calculate Cart Subtotal normally.

Do NOT modify existing subtotal logic.

--------------------------------------------------

STEP 2

Calculate Delivery Charge

IF Delivery Charges OFF

deliveryCharge = 0

ELSE

IF Free Delivery Threshold Enabled
AND subtotal >= threshold

deliveryCharge = 0

ELSE

Apply selected charge mode:

Percentage
OR
Fixed

--------------------------------------------------

STEP 3

Calculate Handling Charge

IF Handling Charges OFF

handlingCharge = 0

ELSE

IF Free Handling Threshold Enabled
AND subtotal >= threshold

handlingCharge = 0

ELSE

Apply selected charge mode:

Percentage
OR
Fixed

--------------------------------------------------

STEP 4

Grand Total

grandTotal =
subtotal
+ deliveryCharge
+ handlingCharge
+ existing taxes
- existing discounts

VALIDATION RULES
==================================================

- Percentage and Fixed can never be active together.

- Free Threshold amount cannot be negative.
- Percentage cannot exceed 100.
- Fixed charge cannot be negative.

- Preserve all existing store functionality.

==================================================
FREE DELIVERY PROGRESS LOGIC
==================================================

The popup currently displays:

"Add ₹238 More For Free Delivery"

This value must NO LONGER be hardcoded.

It must be calculated from the Delivery Charges settings.

--------------------------------------------------

IF Delivery Charges OFF

Hide:

- Free Delivery Progress Bar
- Free Delivery Message

Reason:

No delivery system exists.

--------------------------------------------------

IF Delivery Charges ON
AND Free Delivery Threshold Enabled

Show:

Progress Bar

AND

Add ₹X More For Free Delivery

Where:

remainingAmount =
deliveryFreeThreshold - cartSubtotal

Example:

Threshold = ₹500

Cart = ₹262

Remaining = ₹238

Display:

Add ₹238 More For Free Delivery

--------------------------------------------------

IF cartSubtotal >= threshold

Display:

🎉 Congratulations!
You have unlocked FREE Delivery.

Progress Bar = 100%

--------------------------------------------------

IF threshold feature disabled

Hide:

- Progress Bar
- Free Delivery Message

==================================================
PROGRESS BAR CALCULATION
==================================================

progressPercentage =
(cartSubtotal / threshold) × 100

Limit maximum value to 100%.

Examples:

Threshold ₹500

Cart ₹250

Progress = 50%

--------------------------------------------------

Threshold ₹500

Cart ₹400

Progress = 80%

--------------------------------------------------

Threshold ₹500

Cart ₹600

Progress = 100%
