# Pathak Bhandar PWA Installation Guide

## What is a Progressive Web App (PWA)?

A Progressive Web App combines the best features of web and mobile apps. Users can install Pathak Bhandar directly from their browser and use it like a native app with:

- **Offline Access**: Browse products and cart even without internet
- **Push Notifications**: Get real-time order status updates
- **App-like Experience**: Full-screen interface without browser bars
- **Quick Access**: Launch from home screen like any other app
- **Automatic Updates**: Always get the latest features

## Installation Instructions

### Chrome (Desktop & Mobile)
1. **Open** Pathak Bhandar website in Chrome
2. **Look for** the install prompt that appears at the bottom of the screen
3. **Click "Install"** button in the prompt
4. **Alternative method**: Click the address bar install icon (⊕) or three-dot menu → "Install Pathak Bhandar"
5. **Confirm installation** in the dialog that appears

### Edge (Desktop)
1. **Visit** the website in Microsoft Edge
2. **Click** the three-dot menu (⋯) in the top right
3. **Select** "Apps" → "Install this site as an app"
4. **Name** your app (default: "Pathak Bhandar")
5. **Click** "Install"

### Safari (iOS)
1. **Open** website in Safari on iPhone/iPad
2. **Tap** the share button (□↗) at the bottom
3. **Select** "Add to Home Screen"
4. **Edit** the name if desired
5. **Tap** "Add" in the top right

### Android Chrome/Samsung Internet
1. **Visit** the website
2. **Tap** the browser menu (three dots)
3. **Select** "Add to Home screen" or "Install app"
4. **Confirm** the installation

## Troubleshooting

### Installation Option Not Appearing?
- Ensure you're using a supported browser (Chrome, Edge, Safari)
- Check that the website is served over HTTPS
- Try refreshing the page or clearing browser cache
- Some browsers require multiple visits before showing install prompt

### App Not Working Offline?
- Make sure the app was properly installed (not just bookmarked)
- Check that you've granted notification permissions
- Try closing and reopening the app
- Clear app cache in browser settings if issues persist

### Notifications Not Working?
1. **Check permissions**: Ensure notifications are allowed for the app
2. **Browser settings**: Verify push notifications are enabled
3. **Device settings**: Check that notifications are allowed system-wide
4. **Re-subscribe**: Log out and log back in to refresh notification subscription

## Uninstalling the PWA

### Chrome/Edge (Desktop)
1. **Right-click** the app icon in taskbar or desktop
2. **Select** "Uninstall" or go to Chrome Settings → Apps
3. **Confirm** uninstallation

### Mobile (iOS/Android)
1. **Long-press** the app icon on home screen
2. **Select** "Remove App" or "Uninstall"
3. **Confirm** removal

## Technical Details

### Browser Support
- **Chrome**: Full support (Android 6.0+, Windows 10+)
- **Edge**: Full support (Windows 10+)
- **Safari**: Basic support (iOS 11.3+, macOS 10.14+)
- **Firefox**: Limited support (Android only)

### System Requirements
- **Storage**: ~10MB for app and cached data
- **RAM**: Minimal impact on device performance
- **Network**: Works on 2G/3G/4G/5G/WiFi connections
- **Offline storage**: Up to 50MB for cached products and data

### Security
- **HTTPS only**: All data transmission encrypted
- **Same-origin policy**: Secure data handling
- **Permission-based**: User controls all app permissions
- **No system access**: Runs in browser security sandbox
